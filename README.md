# Smart City Infrastructure System

A console-based C++ application that simulates how a city administration monitors
and manages infrastructure. It was built as the final project for our Data
Structures course.

## Features

- Road & Transportation Management (add, view, update, delete, search, sort)
- Public Facility Management (schools, hospitals, parks, and more)
- Emergency Service Management (ambulances, fire stations, police units)
- Utility Monitoring (water, electricity, waste) using a dynamic array
- Citizen Service Requests (Pending, In Progress, Resolved)
- City Statistics generated with loops
- Search & Sort Center (linear search, binary search, bubble/selection/insertion sort)
- Road connectivity matrix with row processing and matrix multiplication

## Data structures and concepts used

Arrays, structs, pointers, dynamic memory (`new[]` / `delete[]`), 2D arrays
(matrices), searching, sorting, Big-O analysis, modular programming, and input
validation.

## How to run

    g++ src/*.cpp -Iinclude -o smartcity
    ./smartcity
